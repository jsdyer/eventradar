    Source and coverage

    Data: Has Things (hasthings.com). Open the Metro Vancouver listings feed. Each feed supplies listing metadata under ODbL 1.0. Listings depend on participating local sources and can be sparse. Feeds can reach the 1,000-showtime limit before the end of their date window. All showtimes use the event city’s timezone. Feed requests go to Has Things. Search filters, imports and plans run on this device.

    Atlantic coverage includes Halifax, Moncton, Fredericton, Charlottetown and St. John’s. Northern feeds cover Whitehorse, Yellowknife and Iqaluit.

    Langley has direct venue calendars and local imports. A source date without a clock time is marked “Time unlisted.” Check the organizer before travelling or buying tickets.
